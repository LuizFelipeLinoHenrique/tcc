# PalletCore

O PalletCore é um sistema de gestão que reúne cadastros de clientes, fornecedores e produtos, pedidos com múltiplos itens e acompanhamento financeiro. O painel inicial consolida informações dessas áreas.

| [Fluxo de caixa](fluxo-de-caixa.md) | Lançamentos, projeção, filtros e vínculo com pedidos |
| [Arquitetura e banco de dados](arquitetura-e-banco.md) | Rotas, organização do código, tabelas, RPCs e migrações |
| [Testes e dados demonstrativos](testes.md) | Suítes automatizadas e roteiro de conferência no aplicativo |

Para operar o sistema, comece pelo manual. Para preparar um ambiente de desenvolvimento, siga o guia de instalação e confira os pré-requisitos do banco.
